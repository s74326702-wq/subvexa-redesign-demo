Steam FAQ

Which Steam region should I buy?

Buy the region that matches your Steam account's country. A USA code only works on a USA account.

How fast is delivery?

Instant after payment is confirmed: the code appears in My Orders and in your email. Click Show Code to reveal it.

Can I get a refund after delivery?

No — once a valid code is delivered it cannot be refunded or exchanged. If you paid but no code was delivered, contact support@subvexa.shop for a refund.

What if my code shows as already used or invalid?

Contact support with your order number and the exact error message. Do not publish the code anywhere.

Can I pay with crypto?

Yes — USDT (BEP20). The exact amount and wallet address are shown at checkout. See Payment Methods.

Do Steam cards expire?

Check the expiry on the product page before paying. Some regional cards carry an expiry date.
